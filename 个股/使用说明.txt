
# A股历史数据批量获取程序使用说明

## 文件说明

1. **A股股票列表.csv** - 所有A股的股票代码和名称列表（共5528只）

2. **原始数据/** - 存放每只股票的原始历史数据（OHLCV格式）

3. **完整指标/** - 存放每只股票的完整数据，包含所有技术指标

4. **已处理股票.txt** - 记录已成功处理的股票，断点续传用

## 程序说明

- `get_stock_list.py` - 只获取股票列表
- `test_first_10.py` - 测试程序，处理前10只股票（已测试可用）
- `get_all_a_stocks_final.py` - 主程序，处理所有5528只A股

## 计算的技术指标

### 1. 移动平均线
- MA5/MA10/MA20/MA30/MA60/MA120/MA250 - 简单移动平均
- EMA5/EMA10/EMA20/EMA30/EMA60/EMA120 - 指数移动平均

### 2. 趋势指标
- MACD、MACD_Signal、MACD_Hist
- DMI指标：+DI14、-DI14、ADX、ADXR
- ROC（变动率）、ROC_MA6
- MTM（动量）、MTM_MA

### 3. 超买超卖指标
- RSI（14日相对强弱）
- KDJ（K、D、J线）
- WR（威廉指标）
- CCI（商品通道指标）

### 4. 通道指标
- BOLL_Mid/Upper/Lower（布林带）
- BOLL_Width（布林带宽度）

### 5. 量价指标
- OBV（能量潮）、OBV_MA5/MA10
- VR（成交量变异率）
- Vol_MA5/MA10/MA20（成交量均线）
- Vol_Ratio（成交量比率）

### 6. 乖离率
- BIAS6/BIAS12/BIAS24

### 7. 波动指标
- TR（真实波幅）
- ATR（平均真实波幅）

### 8. 辅助指标
- Price_Max/Min_5/20/60（高低点）
- Vol_Max/Min_20（成交量高低）
- Pct_Change（涨跌幅）

## 使用步骤

### 方法1：完整处理（推荐）
直接运行 `get_all_a_stocks_final.py`：
```bash
python get_all_a_stocks_final.py
```
- 程序会自动处理所有5528只股票
- 支持断点续传，中断后重新运行会继续
- 每只股票处理间隔0.1秒，避免请求过快

### 方法2：测试运行
先运行 `test_first_10.py` 测试：
```bash
python test_first_10.py
```
只会处理前10只股票，验证程序是否正常

## 注意事项

1. **网络要求** - 程序需要稳定的网络连接访问数据源
2. **运行时间** - 处理5528只股票预计需要较长时间（取决于网络速度）
3. **存储空间** - 每只股票数据约50-200KB，总数据量预计几百MB
4. **中断处理** - 程序支持断点续传，已处理的股票会记录在"已处理股票.txt"中
5. **数据时间范围** - 默认从2021-01-01开始获取（可修改程序中的 start_date）
