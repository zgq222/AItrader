## 🎯 脚本功能说明

### 1. update_stocks.py - 主更新脚本（推荐使用）
**功能**：
- 自动检测并更新已有股票的最新数据
- 对缺少技术指标的股票自动补全
- 对完全没有数据的股票完整获取
- 支持断点续传，自动跳过已处理的股票
- 智能限速，防止请求过快

**运行方式**：
```bash
python update_stocks.py
```

**处理逻辑**：
- 如果已有原始数据和完整指标：检查是否需要更新，只获取最新数据
- 如果有原始数据但无指标：读取现有数据，重新计算所有指标
- 如果什么都没有：完整获取历史数据并计算指标

### 2. test_update.py - 测试脚本（前10只）
快速测试功能是否正常，只处理前10只股票

### 3. test_delete_and_update.py - 删除恢复测试
测试数据删除和恢复功能（已验证可用）

## 🚀 日常使用

### 首次完整获取（已完成）
你现在已经拥有完整的5198只A股数据了，无需再运行 get_all_a_stocks_final.py

### 每日更新
每天收盘后运行：
```bash
python update_stocks.py
```
脚本会自动：
1. 检查哪些股票的数据需要更新
2. 只获取新的交易日数据
3. 重新计算所有技术指标
4. 保存更新后的数据

### 补全缺失指标
如果某些股票的指标文件丢失，脚本会自动检测并补全

## 💡 技术细节

### 数据源
- 使用 AkShare 的 `stock_zh_a_daily` 接口
- 不复权数据（adjust=""）
- 上证股票加 "sh" 前缀，深证加 "sz" 前缀

### 文件名格式
```
{股票代码}_{股票名称}_原始数据.csv
{股票代码}_{股票名称}_完整指标.csv
```
特殊字符会自动清理

### 日期范围
- 默认从2021-01-01开始（可在脚本中修改）
- 更新到当天（today）

### 限速
- 请求间隔0.1秒
- 防止触发数据源限制
