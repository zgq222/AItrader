## 1.26 · 双层自选延伸与行业排名排序

延伸分为“第一部分 · 两连进攻”和“第二部分 · 单进攻”。共同前提是前一交易日收阴（收盘价低于开盘价），或者前一交易日下跌（收盘价低于再前一交易日收盘价）；低开收阳但较前收盘下跌，以及下跌的十字星也可满足条件。比较日期严格按市场交易日历，缺少比较日时不使用更早日K替代；如果已能确认收阴，缺少比较日不影响阴线分支成立。

第一部分要求最新交易日的15分钟有效行为序列出现连续两个独立的进攻实线框；第二部分为至少已出现一个进攻实线框、尚未形成两连进攻的观察池。两个部分不重复，形成两连后进入第一部分。计数继续忽略黄色持平框和包含虚线框，普通K线不打断，实线减仓框打断；相邻放量K线合并的同一个框只算一次。已在当日成立的组合不因后续减仓撤销。

两部分与自选股均按行业分类，并直接按手机板块轮动的综合行业排名升序排列，使用全体行业的强度50%+广度50%排名，不对自选子集重新排名。行业标题显示全市场排名和分母，标注排名交易日；未评分及缺排名行业排在后面，待分类置于最后。同名次或均无排名时按行业名称稳定排序，行业内仍收藏优先。轮动排名刷新后同步更新自选与两部分行业顺序，保留各部分独立的折叠状态。未取得轮动排名时提示刷新，不伪造排名。

个股保留概念标签、前日阴线或下跌证据及15分钟框定位入口；单进攻点击定位其进攻框，两连进攻点击定位第二个进攻框。新筛选结果保存单进攻和两连进攻信息，旧版缓存显示重新检查提示。持仓减仓通知、去重及止损线沿用原逻辑。

## 1.23 · 与网页一致的放量框选规则

15分钟图采用网页5分钟图的放量框选算法，使用各自周期的数据：当前日之前20个完整交易日的全部15分钟成交量中位数作为基准，量比≥2.5就框选；一天需16根有效且已结束的15分钟K线才能进入后续日的基准。当前日不参与自己的基准，避免回看时受当日后续成交量影响。移除原来的前20根均量、实体幅度、突破前6根高低点、收盘位置及跨午休/隔夜价格连续性限制。

相邻达标K线合并，不区分每根的涨跌方向；仅同日、相邻记录且相隔15分钟合并，不跨午休、隔夜或日内缺根。整框末根收盘高于首根开盘为红框“主力进攻”，低于为绿框“主力减仓”，相等为黄框“放量持平”。框覆盖整段最高与最低价；按网页相同规则处理相邻行为框的传递包含关系，内层框用虚线，持平框不参与包含比较。文字保留最近4项或所选项，图中全部达标框仍可随拖动、缩放查看。名称描述量价方向，不代表真实账户行为。

腾讯原生15分钟请求扩大为640根（实测返回640根），为近期图表补足20个完整交易日基准；原有缓存可读取，刷新后补齐。历史不足或中位数为0时明确提示暂无判断，不使用较短基准替代。选中K线展示本根量比及中位成交量；横屏、持仓止损、概念标签保留。15分钟与5分钟的合并粒度不同，规则相同不代表逐根结果相同。

### 自动刷新

打开应用时自动刷新，此后应用在前台每10分钟更新一次两个选股列表及自选报价；当前个股日K页同步更新行情和指标。切换页面共用同一刷新时钟，任务未完成时不重复扫描。应用退到后台暂停计时回调，超过10分钟后重新进入会立即补刷新。已经开始的同步任务可继续完成。不是后台或锁屏下持续每10分钟运行的任务。

板块页填写电脑局域网地址后，每10分钟从电脑接口刷新当前板块日K/成交量；未设置地址时使用APK内置快照，不会把离线快照标成最新数据。电脑地址例如 `http://192.168.1.8:8000`，手机与电脑需能互访。失败时保留当前图表，显示错误。自动刷新保留图表缩放、历史位置和指标选择。

自选名单保存在手机本地，按同花顺行业自动分类，每个行业提供板块日K入口。选股卡片和个股日K页可加/移出自选，亦可输入六位沪深代码。自选列表显示最新价、当日涨幅和行情时间；失败时保留此前报价。扫描不会覆盖自选名单。

### 选股和图表

5分钟选股仍使用原来的日线条件：沪深主板非ST；最新MA20严格高于前一日；最近30交易日有收盘涨停；连续三日收盘低于开盘或前收盘，第3日必须为最新交易日的前一个交易日，不拼接停牌缺失日期。

30日涨幅为 `(最新价 / 最近30交易日最低low - 1) × 100%`，前150只确定行业，再取每个行业正涨幅前50只。保留行业分类、行业内及全市场排名、板块指数子列表。盘中按当前报价暂算，收盘后确认。

个股图表支持日K、成交量、MA5/10/20、MACD、KDJ、RSI14、BOLL、VI14，拖动和双指缩放。板块内置90个行业最近240根日K，来源及日期展示在图表页；运行 `python mobile-hammer/sync_board_kline.py` 后重新编译可更新快照。

两个选股列表共享原始日K缓存，同日刷新替换最新报价。首次同步需要下载历史，耗时可能超过一个刷新周期；部分股票历史获取失败时保留上次选股结果。报价源异常会明确提示。
